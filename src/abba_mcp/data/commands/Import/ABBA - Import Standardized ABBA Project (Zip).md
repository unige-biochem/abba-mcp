# ABBA - Import Standardized ABBA Project (Zip)

Menu: `Plugins > BIOP > Atlas > Multi Image To Atlas > Import > ABBA - Import Standardized ABBA Project (Zip)`  
Class: `ch.epfl.biop.atlas.aligner.command.ImportStdZipStateCommand`

Opens a standardized ABBA project zip, created with 'Export Standardized ABBA Project (Zip)', in a new ABBA window: the atlas and slicing orientation stored in the zip are loaded, then the downscaled slices and their registrations.

## Inputs

- `zip_file` (File) **Standardized project (.zip)**
  Zip file created with 'Export Standardized ABBA Project (Zip)'.
