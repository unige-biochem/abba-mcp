# ABBA - Close session

Menu: `Plugins > BIOP > Atlas > ABBA - Close session`  
Class: `ch.epfl.biop.atlas.aligner.command.ABBACloseCommand`

Closes an ABBA session and releases it. Unsaved work is lost.

## Inputs

- `mp` (MultiSlicePositioner) **ABBA session**
  The ABBA session the command acts on.
