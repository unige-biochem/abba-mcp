# Create Atlas from Images

Menu: `Plugins > BIOP > Atlas > Create Atlas from Images`  
Class: `ch.epfl.biop.atlas.custom.AtlasFromImagePlusCommand`

A simple way to create an atlas.

## Inputs

- `atlas_name` (String)
- `atlas_precision_mm` (Double)
- `label_image` (ImagePlus) **Label Image**
- `structural_images` (ImagePlus)
