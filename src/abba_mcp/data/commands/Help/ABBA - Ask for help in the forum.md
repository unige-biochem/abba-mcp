# ABBA - Ask for help in the forum

Menu: `Plugins > BIOP > Atlas > Multi Image To Atlas > Help > ABBA - Ask for help in the forum`  
Class: `ch.epfl.biop.atlas.aligner.command.ABBAForumHelpCommand`

Opens a new post draft on the image.sc forum in a web browser, pre-filled with the versions of ABBA and its dependencies.
