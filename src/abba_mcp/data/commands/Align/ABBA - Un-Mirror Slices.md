# ABBA - Un-Mirror Slices

Menu: `Plugins > BIOP > Atlas > Multi Image To Atlas > Align > ABBA - Un-Mirror Slices`  
Class: `ch.epfl.biop.atlas.aligner.command.MirrorUndoCommand`

Removes the mirroring of the selected slices, made with 'Mirror Slices', while keeping the registrations done afterwards.

## Inputs

- `mp` (MultiSlicePositioner) **ABBA session**
  The ABBA session the command acts on.
