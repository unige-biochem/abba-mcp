# ABBA - Remove Last Registration

Menu: `Plugins > BIOP > Atlas > Multi Image To Atlas > Align > ABBA - Remove Last Registration`  
Class: `ch.epfl.biop.atlas.aligner.command.RegisterSlicesRemoveLastCommand`

Removes the last registration of each selected slice (it can be undone).

## Inputs

- `mp` (MultiSlicePositioner) **ABBA session**
  The ABBA session the command acts on.
