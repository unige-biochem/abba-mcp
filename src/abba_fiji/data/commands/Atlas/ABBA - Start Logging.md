# ABBA - Start Logging

Menu: `Plugins > BIOP > Atlas > ABBA - Start Logging`  
Class: `ch.epfl.biop.atlas.aligner.command.ABBAStartLogCommand`

Opens a debug window which logs the slice events of an ABBA session (creation, deletion, actions).

## Inputs

- `mp` (MultiSlicePositioner) **ABBA session**
  The ABBA session the command acts on.
